# Title artwork

Created with the built-in image generation tool, using `output/ui-concepts/start.png` as the visual reference. PNG files retain their generated alpha channels. The landscape samples a 640×360 grid with nearest filtering; clouds use continuous UV movement and linear sampling for smooth translation. Button frames and icons are drawn in Godot, rather than baked into the artwork.

- `landscape.png`: mountains, lake, ruins and foreground, with transparent sky.
- `clouds.png`: original transparent cloud bank, kept as an edit source.
- `clouds-tile.png`: active user-edited horizontal tile, now 1672×665. Its source proportions are preserved at runtime.
- `landscape_mask.png`: user-painted 1672×941 water mask, matching `landscape.png`. White enables the effect, black excludes it, and gray reduces strength. Sampled as data without color-space conversion.
- Sky: `shaders/title_sky.gdshader`.
- Motion: `shaders/title_clouds.gdshader` and `shaders/title_water.gdshader`.

The sky and water share `shaders/title_cloud_motion.gdshaderinc`. Water samples a mirrored version of the actual cloud texture with surface distortion, rather than leaving the painted purple-pink streak fixed. Cloud drift preserves the user's current 8.4 virtual pixels per second. The user fixed the tile edges, so sky and reflection now wrap the entire texture directly. There is no overlap, edge fade, or color-derived water mask. Cloud rectangle coordinates are supplied to the water shader so cropped image dimensions remain aligned with the reflected sky. The original generation prompts below document the source artwork before manual edits.

## Horizontal tile edit prompt

Input: `clouds.png`. Output: `clouds-tile.png`. Built-in ImageGen, transparent output.

Use case: precise-object-edit. Edit the supplied cloud-only transparent pixel-art layer into a HORIZONTALLY TILEABLE panoramic game cloud texture. Preserve its coral-peach sunset highlights, muted lavender-violet shadows, crisp stepped pixel clusters, overall large billowing cloud shapes and genuinely transparent background. No sky color or ground or text. CRITICAL: left and right boundaries must connect seamlessly when copies are placed side by side; matching cloud silhouette height, matching opacity, matching color and shading at the two edges, continuous cloud formations across the wrap seam. Imagine this texture painted on a cylinder. No fading at the left or right edge, no vertical transparent stripe, no cut-off mismatched masses. Keep large transparent areas above and below the clouds. Wide 16:9 canvas, same visual pixel scale as original. Retain asymmetric interesting cloud peaks throughout the middle; make only the edge regions join naturally. Real RGBA transparency, not a drawn checkerboard.

## Landscape prompt

Use case: stylized-concept. Production game asset, widescreen 16:9 layered pixel-art title-screen landscape. The attached image is STYLE AND COMPOSITION REFERENCE ONLY. Create a new clean landscape matching its lush turquoise alpine lake, violet snowy mountain range, ivy-covered ancient stone chess ruins and huge ivory chess statues on a checkered stone terrace on the RIGHT. Strong sunset warm highlights and deep blue-violet shadows, deliberate crisp pixel clusters like a beautifully crafted 640x360 pixel-art game background, no painterly blur. Left 40% is quiet open turquoise water with distant low pine shores so menu UI can be placed over it. Right edge has tall broken classical columns, center-right an ancient arch at lake edge, right foreground a mossy stone chess terrace with king, knight, rook and pawn statues. Composition full-bleed rectangular LANDSCAPE canvas, no border or isolated floating island. Water extends to all lower edges. Horizon at roughly 48% height, mountain peaks at 24% height. IMPORTANT LAYER REQUIREMENT: render ALL SKY ABOVE THE MOUNTAIN SILHOUETTE AS GENUINE TRANSPARENCY, including between columns, no sky color, NO CLOUDS at all. Retain the entire mountain range, trees, lake, rocks, ruins and foreground. Transparent pixels only where sky would be. Upper left mostly transparent behind future title. No text, NO TITLE, NO LETTERING, no UI buttons, no icons, no frame, no watermark. This is the mountains+water+foreground alpha layer to composite over separately moving clouds.

## Cloud prompt

Use case: stylized-concept. Production 2D GAME BACKGROUND LAYER, panoramic 16:9 aspect ratio. Reference image is style and cloud color reference ONLY. Create ONLY a broad bank of billowing sunset clouds in crisp hand-crafted pixel-art, coral peach illuminated upper edges and lavender purple shadow planes, matching the reference's clouds. These are to drift very slowly behind a separate alpine mountain scene. REAL ALPHA TRANSPARENCY around the clouds. NO sky fill, no mountains, no landscape, no lake, no ruins, no chess pieces, no ground, no text, no border. Composition: large irregular cloud masses arranged as a horizontal panoramic bank across the upper and middle canvas, some small detached wisps, soft volume expressed entirely through deliberate HARD PIXEL CLUSTERS with clear stepped outlines, not blur. Upper third and spaces between clouds are transparent. Lower third mostly transparent with a few tapering wisps. Leave transparent margin at left and right edges for tiling, no clipped cloud ends. Sunset light from upper right, warm peach and rose highlights, muted periwinkle and violet shadows. Consistent pixel scale with a 640x360 pixel-art game. A clean cloud-only cutout layer, not a complete scene.
